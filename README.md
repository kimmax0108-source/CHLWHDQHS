# 자재 문서 표준화 v2.0.0

건설현장 자재업무에서 사용하는 **구매 품의서 양식**, **지출결의서**, **자재 입고 청구관리**를 하나의 Windows 프로그램으로 통합한 GitHub 업로드용 프로젝트입니다.

## 통합 화면

프로그램 시작 화면과 좌측 메뉴에서 다음 세 업무를 바로 실행합니다.

1. **구매 품의서 양식**
   - 견적대비표 → 내역서 → 구매품의서 순서로 작성
   - 최종 단계에서만 하나의 Excel 파일로 내보내기
   - 출력 시트 순서: `구매품의서 → 내역서 → 견적대비표`
2. **지출결의서**
   - 원가안분, 적요, 구매품목, 업체 계좌정보 입력
   - 기존 양식과 계산 정책을 유지한 Excel 출력
3. **자재 입고 청구관리**
   - `.xlsx`, `.xlsm`, `.xls` 대장 읽기
   - 표준 시트 `잡자재·주자재·안전` 다중 선택 및 기존 단일 대장 호환
   - 입고월 기준 조회, 수동 분류, 청구 제외, 이월, 이력, 백업, Excel 출력

## v2.0.0 주요 변경

### 공통 UI

- PySide6 기반의 단일 디자인 시스템으로 통일
- 회색 작업 배경을 제거하고 흰색 카드, 절제된 테두리, 통일된 간격과 강조색 적용
- 시작 화면 3개 업무 카드 및 좌측 직접 이동 메뉴
- 공통 색상, 버튼 높이, 카드, 표 헤더, 입력창, 상태표시 적용
- 긴 업체명·품명·규격은 툴팁과 사용자 조절 열 너비로 전체 확인
- 상세 표는 열 이동, 열 너비 조절, 가로 스크롤, 행 정렬 지원
- 모든 섹션 제목을 카드 테두리 위가 아니라 흰 카드 내부에 배치해 입력영역과 제목 정렬 통일
- 견적업체/대표품목 분할과 입력화면/미리보기 분할에 실제 드래그 가능한 고급형 그립 적용
- 업체별 순위·최종선정·가실행 영역은 높이 248px 고정으로 분리해 불필요한 세 번째 분할바 제거
- 우측 하단은 `문서 요약 → 단계 표시 → 이전/다음`의 하나의 흐름으로 재구성

### 구매 품의서 양식

- 견적대비표·내역서·구매품의서의 이전/다음 이동 구현
- 중간 단계의 중복 Excel 내보내기 제거, 최종 내보내기만 유지
- 견적업체/대표품목/상세품목 추가·삭제·이동
- 업체별 공급가액·부가세·합계·순위 계산
- 업체 평균 또는 공내역서 직접입력 방식의 가실행
- 원단위 반올림·올림·버림·소수 유지
- 비율 표시는 소수점 한 자리
- 미리보기와 Excel 출력이 동일한 데이터·계산값을 사용하도록 통합
- 구매품의서·내역서·견적대비표 미리보기의 열·합계·비율·원화 표시를 실제 출력 구조와 일치

### 지출결의서

- 기본정보·원가안분·적요·계좌정보·미리보기를 동일한 흰 카드와 그리드 기준으로 정렬
- 입력영역과 미리보기 사이 폭을 사용자가 직접 조절할 수 있는 분할바 적용
- 기존 원가안분·금액계·수량계·계좌정보·한글금액 기능 유지
- 업체 수에 따른 계좌행과 하단 문서 위치 자동 조정
- Excel 출력 시 기존 양식, 도형, 말소선, 인쇄 설정 보존

### 자재 입고 청구관리

- 원본 Excel은 읽기 전용으로 사용하며 관리값은 숨김 JSON에 별도 저장
- 공식 공급가액은 원본값을 유지
- `수량 × 단가` 원단위 반올림값과 원본 공급가액 비교
- 불일치/검토불가 행 색상 표시
- 연도·월·공종·원본시트·구입처·품명·통합검색 필터
- 당월 입고분·전월 이월분·다음 달 이월분·실제 청구대상 요약
- 상세내역에서 수동 청구분류 변경/원복
- 청구대상 제외/제외 취소
- 관리메모 및 변경 이력
- 이전 달 내역 선택 가져오기, 다음 달 이월, 이월 취소
- 동일 행은 지문값으로 관리하여 중복 생성 방지
- 연말 `12월 → 다음 해 1월` 처리
- 조회 프리셋 저장·적용·수정·삭제
- 관리 JSON 수동 백업·복원
- 저장 직전 자동 백업, 최근 5개 유지
- 품명별·구입처별·시트별 집계와 Excel 내보내기

## 실행

### 개발 실행

```bat
run_dev.bat
```

또는:

```bash
python -m pip install -r requirements-dev.txt
set PYTHONPATH=src
python main.py
```

지원 Python은 `3.11 이상 3.15 미만`입니다.

## 테스트

```bash
python -m pytest
python -m ruff check .
```

테스트 범위에는 계산, 템플릿 출력, 표준 대장 다중 시트 로드, 이월/제외/분류, 관리 JSON 백업·복원, 원본 파일 불변, 통합 패키징, Qt 화면 생성 검사가 포함됩니다.

## Windows EXE 빌드

```text
GitHub 저장소 → Actions → Build Windows EXE → Run workflow
```

완료 후 `material-document-standardization-v2-windows` 아티팩트에서 `material_document_standardization_v2.0.0_windows.zip`을 내려받습니다.

## GitHub 업로드 최적화

- GitHub 웹 업로드의 100개 파일 제한에 맞춰 전체 구성을 **92개 파일**로 정리했습니다.
- 실행에 사용되지 않는 UI 시안 이미지, 중복 업로드 보조파일, 중복 샘플, 미사용 아이콘은 제외했습니다.
- 프로그램 실행, 자동 테스트, Windows EXE 빌드에 필요한 소스·템플릿·워크플로는 모두 유지합니다.

## 저장 파일

- 구매 품의서/지출결의서 작업파일: 사용자가 지정한 경로
- 자재 청구관리 JSON: 원본 Excel과 같은 폴더의 숨김 파일
  - `.<원본파일명>_청구관리.json`
- 자동 백업 폴더:
  - `.<원본파일명>_청구관리_백업`

원본 대장은 프로그램이 직접 덮어쓰지 않습니다.
