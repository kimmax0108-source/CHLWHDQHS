# 화면별 UI 기준

배포 파일 수를 줄이기 위해 중복 UI 시안 PNG는 저장소에서 제외했습니다. 실제 화면은 아래 기준으로 구성합니다.

## 1. 시작 화면

- 프로그램 실행 직후 표시
- 구매 품의서, 지출결의서, 자재 입고 청구관리 업무 카드 제공
- 각 카드에서 해당 업무 화면으로 즉시 이동
- 버전과 프로그램 설명 표시

## 2. 공통 화면 구성

- 좌측 고정 내비게이션과 우측 업무 영역
- 동일한 카드, 표, 버튼, 입력창, 상태표시 디자인
- 업무별 강조색 적용
- 긴 업체명·품명·규격은 가변 열과 가로 스크롤로 확인

## 3. 구매 품의서

- 견적대비표 → 내역서 → 구매품의서 순서의 단계형 화면
- 업체·품목 추가, 삭제, 순서 변경
- 최종 단계에서 3개 시트를 하나의 Excel 파일로 출력

## 4. 지출결의서

- 원가안분, 적요, 품목, 업체 계좌정보 입력
- 업체 수에 따라 출력 양식의 계좌행과 문서 위치 자동 조정
- 기존 Excel 양식과 인쇄 설정 유지

## 5. 자재 입고 청구관리

- 원본 대장 불러오기와 다중 조건 조회
- 금액 검증, 수동 청구분류, 청구 제외, 이월, 메모, 이력 관리
- 집계표와 상세내역을 Excel로 출력
